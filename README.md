# Sistema-de-Cadastro-de-Clientes-em-Java
Neste projeto pratiquei:  ✅ Criação de classes e objetos ✅ Construtores ✅ ArrayList para armazenamento de dados ✅ Estruturas de repetição e condicionais ✅ Entrada e saída de informações pelo console  O objetivo foi aplicar conceitos de Programação Orientada a Objetos (POO) e criar uma base para projetos maiores.
