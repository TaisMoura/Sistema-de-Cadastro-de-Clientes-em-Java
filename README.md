# Sistema de Cadastro de Clientes em Java

Aplicação desenvolvida em Java para gerenciamento de clientes por meio de uma interface de console.

O projeto foi desenvolvido com foco na prática de conceitos de Programação Orientada a Objetos (POO), estruturas de dados e operações CRUD.

## 🚀 Funcionalidades

- Cadastro de clientes
- Listagem de clientes
- Busca de clientes pelo nome
- Atualização de dados
- Remoção de clientes
- Validação de opções do menu
- Armazenamento dos clientes em memória

## 🛠️ Tecnologias e conceitos

- Java
- Programação Orientada a Objetos (POO)
- Classes e objetos
- Encapsulamento
- Construtores
- Getters e Setters
- ArrayList
- Estruturas condicionais
- Estruturas de repetição
- Scanner
- CRUD
